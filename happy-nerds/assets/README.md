# Happy Nerds assets

Put all Happy Nerds art, audio and design references here (for example the files from the Google Drive design folder). Keep them out of the Homeward Hound folders in the repo root.

Suggested layout:

```
assets/
  reference/   design docs, mock-ups, mood boards (not shipped)
  sprites/     winged brain, gates, backgrounds, UI
  audio/       sound effects and music
```

The game currently draws placeholder shapes in `src/render.ts`. Each one will be swapped for a sprite from here once the art is in.
